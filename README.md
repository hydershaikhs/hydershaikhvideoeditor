## 💎 Features & Capabilities

- **Rich Maroon & White Theme**: Bespoke deep wine maroon (`#580F1B`, `#2A050B`) paired with crisp whites and subtle rose/film grain aesthetics.
- **Interactive Before/After Color Grading Slider**: Real-time slider comparing flat Sony S-Log3 RAW footage against finished cinematic Kodak 2383 film print emulation.
- **Video Lightbox Showreel Player**: Modal video player showcasing commercial reels, documentary edits, and viral short-form videos.
- **Categorized Portfolio Filter**: Instant filter for Commercials & TVCs, YouTube Long-Form, Viral Reels/Shorts, and Color Grading.
- **Interactive Multi-Track Timeline Visualizer**: A custom-styled NLE timeline reflecting Premiere Pro and DaVinci Resolve workflows (A-Roll, B-Roll, Foley Audio, and Kinetic Subtitles).
- **Interactive Investment / Pricing Calculator**: Enables potential clients to calculate real-time project estimates and initiate orders directly via WhatsApp.
- **Client Testimonial Showcase**: Social proof from top creators and agencies.
- **Contact & Inquiry System**: Pre-configured WhatsApp direct messaging, one-click copy email with animated toast notifications, and project brief form.
- **Web Audio API Sound Effects**: Subtle, non-intrusive cinematic sound FX with an instant mute/unmute control.
- **100% Mobile Responsive & Zero-Build**: Ready to host natively on **GitHub Pages**, Vercel, Netlify, or any static web host.

## 🚀 How to Enable GitHub Pages (Live in 30 Seconds!)

To make this website live on the web at `https://hydershaikhs.github.io/hydershaikhvideoeditor/`:

1. Open your repository on GitHub: [hydershaikhvideoeditor](https://github.com/hydershaikhs/hydershaikhvideoeditor)
2. Go to **Settings** (tab at the top right of the repository).
3. In the left sidebar, click on **Pages**.
4. Under **Build and deployment** > **Branch**:
   - Select `main` (or `master`)
   - Select folder: `/ (root)`
   - Click **Save**.
5. Wait ~60 seconds, refresh the page, and GitHub will display your live portfolio URL!
